# Conservation source import batches — 9 November 2026

Production rollout followed on 10 November 2026. See [the release record](SOURCE_ROLLOUT_2026-11-10.md) for deployed commits, activated batches and sources held for access or reuse restrictions. The results below retain the original 9 November audit.

Implementation and read-only audit of the 71 proposed sources. Source management remains administrator-only. No migration was applied to production, no sources were enabled there, and no AI requests were made by these audits.

**22 sources read successfully:** 13 returned adverts and 9 returned a verified empty result. The readers observed 164 source listings, of which 145 meet the existing WildJobs expiry rules. These are observations before cross-source deduplication, not a public job count. **49 sources still need access, URL, configuration or connector work.**

“Read successfully” confirms technical extraction only. It does not establish redistribution permission or approve activation. Current counts are a dated snapshot and will change. Some supplied pages have moved; the catalogue records the tested replacement. The two EthicalJobs entries use direct employer alternatives because the third-party terms restrict redistribution.

## Batch 1 — source management and import safety

- Save a URL as a paused source even when detection fails. Check it, preview jobs, edit its URL/settings, enable after source review, pause, refresh, remove and restore it.
- Queue the full proposed catalogue without enabling imports; check the next three untested entries through admin.
- Reuse the existing importer, AI summaries, source snapshots and canonical jobs. Supported readers cover RSS/Atom and Teamtailor discovery, Lever, iCIMS, Workday, SmartRecruiters, Simplify, configured HTML lists, individual adverts and manual adverts.
- Follow declared pagination within request/time limits. Reject failed detail reads, login challenges, excluded crawl paths, missing required metadata and repeated result pages. Require a second spaced empty observation before withdrawing a previously populated source.
- Keep unknown employment facts and original dates. Store private revision-aware checks and activity; preserve existing job IDs and duplicates supplied elsewhere.
- Keep validated API, document and manually entered advert text through enrichment; a JavaScript application shell cannot replace it before summaries and course matching.
- Extract bounded text PDFs. Documents without a verifiable deadline or useful text require manual entry; automatic OCR is not implemented.

## Verification and release boundary

- Unit and regression suite: source parsing, nested feed fields, comments-feed rejection, navigation headings, failed/repeated pagination, unknown facts, dated/undated PDFs, Workday pagination and administrator-only mutations.
- Embedded PostgreSQL tests execute the existing source migration and the additive extension. They verify service-role invoker access, denied public access, paused drafts, source review, revision races, malformed/partial snapshot rejection, stable IDs/dates and cross-source retirement.
- Typecheck, lint, formatting and production build pass. The ordinary test suite skips the opt-in live audit; live audits were run separately.
- The existing EnvironmentJob feed was checked separately through the new shared reader and still returns a complete valid feed.
- The actual admin page was server-rendered with synthetic checked, blocked and removed sources and its controls verified. Browser visual inspection was blocked because the browser tool disallows local `file:` URLs. A live authenticated mutation flow was not exercised against production.
- Local Supabase CLI testing was unavailable because Docker/Podman is not installed. The PostgreSQL tests use PGlite instead; they are not a full Supabase stack test.

The application and `supabase/migrations/20261110095239_career_page_sources.sql` were released on 10 November 2026. The filename matches the version recorded by the production migration service; it must not be applied there again. Existing feed rows retain their URLs and enabled state. The new catalogue is queued explicitly through admin and starts paused. Remaining connector work is listed above; the manual advert path provides a reviewed fallback, not automatic monitoring.

## Repeating the audit

```sh
WILDJOBS_SOURCE_AUDIT=1 pnpm exec vitest run tests/source-live-audit.test.ts
```

Use `WILDJOBS_SOURCE_FILTER` to select a source-name pattern. Results are written beneath the operating system’s temporary directory in `wildjobs-source-audit/`. Set `WILDJOBS_SOURCE_CAPTURE=1` only when temporary public HTML samples are needed for diagnosis. No database or AI client is used.
