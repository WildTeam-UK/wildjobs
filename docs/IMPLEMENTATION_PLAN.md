## Approved career-guide pilot · 3 November 2026

The user approved implementing the Wildlife Conservation sector guide and Ecologist career guide first, with reusable templates, researched citations, real linked vacancy data, rolling twelve-month statistics and editorial review. Keep WildJobs independent; use the existing database and importer. Do not enable additional occupations or unattended editorial publication as part of this pilot.

Guide prose is structured, versioned editorial content in `lib/guide-content.ts`, with explicit source references and checked dates. Shared route templates and `GuidePage` render it consistently. Published content is a reviewed database snapshot, so a new draft or code content edit does not silently replace approved prose. Layout changes apply across both guide types. Sources need research and a new version when reviewed, rather than a new date without checking them.

The existing canonical job IDs define the samples, excluding merged source copies. Live openings use existing expiry rules; history includes expired adverts posted in the last twelve months. Show observation dates and the collection-coverage limitation, not implied complete annual market coverage. Salary medians use advertised annual GBP minima for paid UK jobs with full-time evidence in the original feed text; exclude pro rata, mixed-grade, nonannual and ambiguous currencies. Require five comparable salaries per displayed median and separate career levels. Never convert currency, annualise hourly rates or invent missing facts.

Use a shared, conservative Ecologist role matcher for guide membership and `?role=ecologist` listings. Preserve original job titles; distinguish seniority. Explicit occupation titles and supported ecological-consultant variants match; spelling variants or mixed occupations require staff review. Staff-approved normalized-title mappings, including exclusions, apply to future adverts. Pilot mappings are occupation-specific, not a new general-purpose AI classification system.

Automatically queue an evidence-backed draft when there are ten distinct detailed matching adverts from at least two named employers. Queue only the existing pilot editorial baseline; this is not an unattended web researcher or AI article-writing service. No extra AI request is added to the importer. Pending drafts are preserved until staff explicitly refresh them. New content versions, changed role mappings and ninety-day review dates require editorial attention. Staff review the guide, sources and sample before atomically publishing a version; retain previous versions. The same source read already performed by the importer supplies private advert evidence; missing originals are clearly labelled RSS fallbacks. Existing adverts can be backfilled in bounded staff-triggered batches.

Apply the additive pilot migration before activating staff review. Anonymous clients can read reviewed title mappings and published revisions only; original advert snapshots are private. Draft routes are labelled previews, marked noindex and excluded from the sitemap until approved. Keep the public preview working against the existing schema during rollout; do not mask unrelated database errors.

## International salaries

Salary parsing is shared by feed fields, linked adverts, AI output and public cards. Preserve original pay and its stated period; use explicit ISO currency codes for currencies other than GBP (£) and EUR (€). Bare $ and ¥ remain ambiguous unless the source supplies a currency. Do not convert currencies or annualise hourly, monthly or fortnightly pay. Description extraction looks for pay wording, excluding nearby budgets, expenses and awards. The existing minimum-salary filter is labelled GBP and matches confirmed annual GBP minimums only; international jobs remain visible without that filter. Existing salary text and numeric columns suffice; no migration, extra service or additional AI call is needed.

Malformed salary units in advert metadata fall back to the matching amount in visible advert text or the RSS pay header. Explicit advertised currencies can clarify bare symbols without overriding stated pay periods.

## Employer branding

Reuse `directory_organisations.logo_url` across an employer’s listings. The existing AI pass chooses an official employer website when no logo is available, using advert links and business email domains as candidates. Normal importer code fetches and checks the employer site and a real logo image; AI never generates logos or guesses image URLs. Simple inline brand SVGs can also be cached. If an advert-linked site blocks the read or its declared images fail, fetch its branded website icon through Google’s public favicon endpoint and embed the image in the cached logo value. Visitors do not request that icon service. Missing-icon responses and generic platform favicons are rejected. Lookups are deduplicated within each batch, bounded in time, and failures leave the existing card fallback without holding publication. The admin logo override remains available.
